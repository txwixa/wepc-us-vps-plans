## 双 ISP 家宽 IP 到底买的是什么

国际 IP 数据库会给每个 IP 打 usage type 标签。机房托管段通常标成 hosting 或 datacenter，住宅宽带段标成 ISP。做账号环境的人要的是后者，这是这条产品线贵出普通美国 VPS 一大截的全部理由。

WePC 的命名方式是把上游写进套餐名：静态家宽、Cogent 家宽、GTT/NTT 家宽。Cogent 和 GTT/NTT 都是做国际带宽的 Tier 1 运营商，页面把名字亮出来，至少你能拿它去核对。市面上另一类产品只写"双 ISP 属性"，机器仍然托管在数据中心段，靠上游声明拿到 ISP 标签。两种叫法在数据库里的表现未必一样，付钱之前值得分清。

还有一层代价，很多宣传页不写：为了维持住宅属性，部分双 ISP 产品不做中国方向的去程优化，甚至会出现 IP 被地理定位到中国大陆的情况。WePC 页面写的是"三网回程优化，无需中转"，措辞落在回程，去程怎么走没有明说。做直播的读者拿机器第一件事就该查归属地和回程路由，别等开播了才发现。

## 4837 和 9929 的实际区别

4837 是联通的普通国际线路，价格低，晚高峰波动明显。9929 是联通精品网，国内方向优先级更高，业内常拿它和电信的 CN2 GIA 类比。按行业普遍口径，普通国际线路回中国延迟 200–300ms 属正常，走优化线路能压到 150–180ms。这不是 WePC 的实测数据，是同类型线路的常见区间，你在不同省份、不同运营商下的结果会有出入。

页面里"无需中转"四个字值得单独解释。做 TikTok 直播的常见做法是在中间加一台中转机把流量接回国内，多一台机器就多一份月费、多一个故障点。回程直连优化能省掉这一环，这就是它比同配置普通美国 VPS 贵、但比"便宜机 + 中转机"两台的组合未必贵的原因。

## 五个必须提前知道的限制

1. **产品页明确写了严禁使用 Shadowsocks 协议。** 这是硬规则，不是建议。手上的方案跑什么协议，买之前先确认。
2. **流量超了限速 3Mbps，不是断网。** 1.5TB 对直播不算宽裕：按 4Mbps 码率估算，一路 1080p 推 8 小时约 14GB，一个月就是 400GB 出头；两三路同时推，1.5TB 会提前见底。被限到 3Mbps 之后只够勉强推低码率，基本等于当天收工。
3. **0.5GB 和 512MB 内存是真的小。** 跑轻量面板、几个脚本没问题，装宝塔再加数据库就别想了。要跑重一点的东西，直接看 6GB 那款。
4. **退款条款要单独确认。** 美国 VPS 的产品页面上没有写退款期限，官网另一个产品分类页挂着 30 Days Money Back Guarantee。这条是否覆盖美国线路，下单前用中文工单问清楚并留档。
5. **澳元结算。** 双币卡会走货币转换，实际扣款按账单日汇率，和你在页面上看到的人民币估算会有几块钱的差。
